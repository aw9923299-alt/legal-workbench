## 原问题逐项复验

### QA-H01｜行动队列数量与实际条目不一致

- 结果：**已修复**。
- 实时证据：三个视口的激活 Tab 均显示“应立即处理 4”；1440 实际渲染 4 行桌面任务，1024 实际渲染 4 条紧凑任务，390 实际渲染 4 张移动任务卡。
- 判断：Badge、Tab 含义和列表成员现已使用同一口径，没有额外混入中优先级任务。

### QA-H02｜1024 状态与操作列被裁切且不可达

- 结果：**已修复**。
- 实时证据：1024 下桌面表格不再显示，改为 4 条紧凑任务行；首条紧凑任务区域为 `x=103–993`、宽 890px，完全处于 1024px 视口内。风险、期限、负责人、等待对象、下一步、状态和“进入事项中心”均可见；页面内未发现越出左右边界的可见元素。
- 交互证据：任务入口可安全进入“法务事项中心”。
- 判断：关键字段和安全入口不再依赖被隐藏的桌面列，也无需不可发现的横向滚动。

### QA-H03｜390 首屏看不到具体待办

- 结果：**已修复**。
- 实时证据：390 下行动队列标题约从 `y=370` 开始，第一张任务卡为 `y≈462–804`，标题、风险、期限、负责人、下一步和事项入口均进入 844px 首屏；页面总高度从首轮约 4124px 降至约 3324px。
- 判断：数据边界提示已收敛为单行信息，异常摘要改为 2×2，首屏重新体现了实际行动优先级。

### QA-M01｜“今天 / 本周 / 全部”假筛选

- 结果：**已修复**。
- 实时证据：三个视口均不存在 Segmented 范围控件；保留的三个任务 Tab 可点击，等待回复和风险升级分别稳定显示 3 条移动任务。
- 判断：未实现的数据范围能力不再以可交互筛选器出现。

### QA-M02｜移动触控目标小于 44px

- 结果：**已修复**。
- 实时证据：390 下顶栏菜单为 44×44px、通知按钮为 44×44px、主操作高 44px、任务入口为 106×44px。Drawer 稳定展开后宽 280px，关闭按钮 44×44px，全部导航项高 44px，Drawer 主操作高 44px。
- 判断：本轮关键移动交互目标均达到 44px 最小热区。

### QA-M03｜12px 元数据对比度不足

- 结果：**已修复**。
- 实时证据：指标提示、任务编号、风险理由和缺失材料元数据的计算颜色均为 `rgb(101, 112, 131)`，即 `#657083`；白底对比度约为 5.00:1。
- 判断：12px 正常文本已超过 4.5:1 的常用可读性门槛，同时仍保留次要层级。

### QA-L01｜桌面标题大于 24px 规格

- 结果：**已修复**。
- 实时证据：1440、1024、390 三档“今日工作台”的计算字号均为 24px。
- 判断：桌面与移动标题层级已统一。

### QA-L02｜默认页持续输出 Ant Design 弃用警告

- 结果：**默认页已修复**。
- 实时证据：三个视口分别重新打开并刷新默认页后，控制台只有 Vite 连接和 React DevTools 信息；无 console error、无 page error、无请求失败、无 HTTP 4xx/5xx。
- 判断：默认“今日工作台”不再输出 `Card bordered` 弃用警告。主操作目的页的剩余警告见下方 Low finding。

## 当前剩余 Finding

### F-L01｜AI 收件箱目的页仍输出 Card 弃用警告

- 严重度：**low**
- 视口 / 路由：390×844；从 `/` 点击“处理待确认消息”进入 AI 收件箱状态
- 位置：浏览器控制台；目的页 Card 组件
- 证据：安全点击主操作后，AI 收件箱正常渲染，未出现 page error、失败请求或 HTTP 4xx/5xx，但控制台出现一次 `[antd: Card] bordered is deprecated. Please use variant instead.`。
- 实际表现：不影响默认页或目的页当前渲染，但仍会污染全应用的控制台错误信号。
- 期望：主操作目的页同样不使用已弃用的 Card API。
- 具体修改建议：后续在 AI 收件箱相关 Card 中将 `bordered` 迁移为当前 Ant Design 版本的 `variant` 写法，并以同一路径复测控制台。
